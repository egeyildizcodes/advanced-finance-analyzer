# Advanced Finance Analyzer Pro

A portfolio-grade C# finance analytics tool that processes CSV transaction data, evaluates financial health, detects budget overruns, identifies anomalies, forecasts future expenses, and generates structured reports.

## Features
- CSV-based transaction import
- Income and expense analytics
- Monthly trend breakdown
- Category insights
- Merchant-level spending analysis
- Budget alert engine
- Recurring payment detection
- Anomaly detection
- Financial health scoring
- Next-month expense forecasting
- Recommendation engine
- TXT and JSON report generation

## Tech Stack
- C#
- .NET 8
- System.Text.Json
- Object-oriented modular architecture

## Project Structure
- `Models/` -> domain models
- `Services/` -> analysis, forecasting, scoring, reporting
- `Data/` -> sample CSV transactions
- `Config/` -> budget configuration
- `Reports/` -> generated outputs
